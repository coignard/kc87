# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.7.0   | :white_check_mark: |
| < 0.7.0 | :x:                |

## Reporting a Vulnerability

Please [report vulnerabilities](https://github.com/coignard/kc87/security/advisories/new) rather than opening a public issue. Thanks!
